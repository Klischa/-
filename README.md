# Приводное / Опорно-ведущее колесо гусеницы «Муравей» z=24 (Шаг 50,5 мм)

Полный комплект конструкторской документации, файлов для ЧПУ резки и полноразмерных лекал (1:1) для приводной звездочки z=24 с трапециевидным зубом под гусеницу снегохода/буксировщика «Муравей».

---

## 1. Геометрические параметры венца z=24

- **Число зубьев ($z$):** 24
- **Шаг цевки ($p$):** 50,5 мм
- **Делительный диаметр ($d$):** 386,9 мм
- **Диаметр вершин ($d_a$):** 408,8 мм
- **Форма зуба:** Трапеция
  - Ширина плоской вершины: 6,97 мм
  - Радиусы скругления вершин: $R1,6 \pm 0,3$ мм
  - Угол наклона боковых граней (профиля): $20^\circ \pm 30'$
  - Радиус закругления впадин: $R3$ мм
- **Посадочные размеры ступицы (оригинал):**
  - Центральное отверстие: $\varnothing 75\text{ H7 } (+0,030)$ мм
  - Крепеж: 9 отверстий $\varnothing 9,5$ мм на диаметре $\varnothing 95$ мм (шаг $40^\circ$)
- **Толщина венца:** 10 мм
- **Материал:** СВМПЭ РЕ-1000 / Капролон ПА-6 / Сталь 09Г2С (толщина 10 мм)

---

## 2. Реализованные конструктивные решения

### Решение 1: Пакет с опорными боковыми катками (щеками)
- Звезда $z=24$ со стандартной высотой зуба ($d_f = 351,9$ мм, $h = 28,45$ мм).
- 2 опорные щеки $\varnothing 381,9$ мм толщиной по 19 мм (капролон / влагостойкая фанера ФСФ / Д16Т) с заходными фасками $3 \times 30^\circ$.
- Пакет стягивается 9 болтами М8×65. Общая ширина пакета **48 мм** (под 50-мм коридор клыков гусеницы «Муравей» с зазором по 1 мм на сторону).
- Скобы гусеницы опираются на гладкие щеки $\varnothing 381,9$ мм, исключая вибрацию и проваливание.

### Решение 2: Звездочка с опорным дном впадин ($d_f = 378,4$ мм)
- Одиночная звезда толщиной 10 мм без дополнительных катков.
- Дно впадины поднято до $d_f = 378,4$ мм ($h = 15,2$ мм), благодаря чему скобы гусеницы мягко ложатся на дно впадин.
